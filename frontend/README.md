# AI Ad Maker for Small Shops - Frontend

This is the frontend of the AI Ad Maker project.

## Technology Stack
The frontend uses React.

## Page Structure
The four main page stages are Upload, Script, Voice, and Video. Each page is intentionally self-contained.

- **Upload**: Product photo upload and description.
- **Script**: Script generation and approval.
- **Voice**: Voice generation and approval.
- **Video**: Final advertisement video and subtitle display.
